# Kodey Kontabs — Brand Kit

Este pacote reúne a identidade visual e um guia prático para desenvolvimento de interfaces do Kodey Kontabs.

## Arquivos principais
- `index.html` — guia completo de identidade visual e componentes.
- `styles.css` — tokens de design e estilos dos exemplos.
- `app.js` — pequenas interações do guia (copiar tokens e alternar exemplos).
- `assets/logo-mark.svg` — símbolo vetorial recomendado.
- `assets/app-icon.svg` — ícone vetorial para app/PWA.
- `assets/brand-board.png` — prancha visual aprovada como referência.
- `assets/kodey-reference.jpg` — logo Kodey original usada como referência.

## Como visualizar
Abra `index.html` diretamente no navegador. Nenhuma dependência externa é necessária.

## Filosofia
A marca deve transmitir: leveza, clareza, organização, confiança e bom humor. Finanças podem ser um assunto pesado; a interface deve tornar o tema mais acolhedor sem parecer infantil ou pouco confiável.
